### ESPECIFICACIONES DE DESARROLLO (SDD)

1. Fase de Análisis y Renderizado Core
- Carga de Mermaid: Inicializa Mermaid.js vía CDN. Configura 'securityLevel: strict' y 'htmlLabels: false' para evitar problemas de CORS o seguridad al abrir el archivo localmente (file://).
- Ejecución Asíncrona: Asegúrate de atar la lógica de interactividad SOLO después de que la promesa de renderizado de Mermaid se haya resuelto completamente y el SVG esté presente en el DOM.

2. Lógica de Interfaz y Manejo del DOM
- Event Delegation (CRÍTICO): NO ates los 'event listeners' (mouseover, mouseout, click) directamente a los nodos del SVG. Usa Event Delegation en el contenedor principal ('#graph-container'). Esto evitará que la interactividad se rompa cuando Mermaid vuelva a renderizar el diagrama al cambiar el tamaño de la fuente.
- Detección Infalible de Nodos: Identifica sobre qué nodo está el usuario leyendo el atributo 'data-id' o buscando la clase '.node' más cercana en la jerarquía del evento, ya que los selectores CSS fallan en nodos con letras y números (ej. 5a, 13b).

3. Sistema de Tooltips y UX Estricta
- Renderizado de Contenido: El texto extraído del documento para el tooltip (Qué pasa en el código, State, etc.) debe inyectarse en el tooltip respetando los saltos de línea originales. Usa 'white-space: pre-wrap' en el CSS del tooltip. Los bloques de código deben tener un fondo oscuro para contrastar.
- Posicionamiento Cuadrante-Consciente: Calcula el 'bounding client rect' del tooltip y compáralo con el tamaño de la ventana ('window.innerWidth/Height'). Si el tooltip se sale por la derecha o por abajo, invierte su posición mediante transformaciones CSS para que nunca se recorte.
- Puente de Hover y Scroll: Si el usuario mueve el ratón del nodo al tooltip, este NO debe cerrarse. Implementa un 'timeout' de gracia (ej. 200ms) en el evento 'mouseout' que se cancele si el ratón entra en el contenedor del tooltip. El tooltip debe permitir scroll interno si el contenido es muy largo.
- Corrección de Coordenadas de Zoom: El posicionamiento del tooltip debe usar las coordenadas relativas al 'viewport' (pantalla) y no las coordenadas internas del SVG, para que no se desfacen si el usuario hace zoom.
